# ⚖️ Teno 行政法（分配與波次實行細則）

> **法源**：本檔依《Teno 治理法典》（`_dev/notes/法典.md`）第二章憲法第 5 條、第三章法律第 2/6 條授權，規範「bug 分配方式」與「波次實行細則」。屬**行政法**（法典下位之執行細則），修訂不須驚動憲法（法典第 1 條）。
> **引用**：法典中以「行政法」引用本檔。本檔內所引之最高位階文件＝法典、GOV-BRIEF.md。

---

## §1 分配方式（不變則）

**一顆 bug 一任務**（法典法律 §2）：
1. 每顆 bug 為**獨立任務**，不得與其他 bug 併成單一 subagent 任務。
2. 同序列以「一顆完成 → 回報 → 總統再派下一顆」進行。
3. 首相 = orchestrator，由總統 spawn；首相自行開審查委員（leaf，唯讀）。
4. **絕不以 delegate_task 派「首相任務本身」** — delegate_task 僅用於首相自開的審查委員。首相是以 `hermes chat` spawn 的獨立 session。

**分配三軸**（法典附則：檔案所有權）：
- 依**檔案所有權白名單**決定歸屬首相。
- 共享檔（`_dev/notes/scope-requests.md`、`src-tauri/Cargo.*`、`lib.rs`）以波次串行解衝突。
- 跨域尾巴（主 bug 已結、白名單外殘鏈）＝ scope-requests 登記 → 總統裁示 → 改派。

## §3 波次實行流程（首相鐵律）

1. **讀檔**：`GOV-BRIEF.md`＋`法典.md`
2. **逐顆循環**：計畫書 → 開審查委員（3 名；簡單 bug 可降 1）→ 過審 → 動工 → 驗證（harness 雙態）→ `version.sh` 升版 → commit → md 落盤 `_dev/notes/subagent-log/`
3. **驗證義務**：harness 必含負控制（剝除修法 bug 精準重現）；送審前實跑過（法律④）
4. **git 義務**：`git add <明確檔案>`（禁 `git add -A`／`git commit -a`）；`index.lock` 睡 3-5s 重試；commit 前 `git status` 分離非本次改動（憲法⑨）
5. **回報**：五欄摘要（commit hash／審查輪數／驗證輸出／計畫書路徑／未完成事項）
6. **殘局**：預算將盡 → 檢查點 `PM<N>-checkpoint.md` 落盤（法律③）
7. **版本**：每顆 bug 結案 commit → `./tools/version.sh`；共享檔不升版不 add

## §4 例外與逃逸門

- **委外 ≠ 跳過審查**：首相自己開的委員全席 ✅ 才算過審；邊界於下限 10 輪。
- **逃逸**：`[skip-version]` 需總統同意；`--no-verify`＝治理事件。
- **審查委員**：leaf，全程唯讀（terminal 只准唯讀＋測試），不給 file 寫入。

## §5 AI 自主運作（離線／睡眠授權）

> **授權來源**（最高層原話，2026-08）：「我要睡了，全權自主運作，離線 8 小時，你決定。」為最高層對總統之**一般性離線授權**，行政法將其制度化，使總統離線時仍有明確行為準據，不必每事回頭問。

### 5.1 觸發條件
- 最高層明示「我要睡了／離線／全權自主／你決定」任一或組合。
- 以「最後一條有效指令」為準；最高層回線後，其下一條訊息即為新的最高指令，自主運作立即結束（下述 §5.5）。

### 5.2 授權範圍（離線期間總統可自主）
| 項目 | 授權 | 邊界 |
|---|---|---|
| **bug 清空** | 依 §1-§3 分配三軸與波次流程 spawn 首相、開審查、動工、驗證、commit | 每顆完整循環，一顆一 commit，不併單 |
| **版本升版** | `tools/version.sh` 逐顆 commit 升版 | 只升不降；衍生指紋同步 |
| **驗證/回歸** | 跑 harness、雙態驗證、regression、build | 未過內測門不 commit |
| **決策裁示** | 對 scope-requests SR、可選項、審查分歧做裁決並落盤 | 裁示需在計畫書/行政法留痕 |
| **波次管理** | 決定下一顆、補槽、殘局交接、檢查點 | 依檔案所有權白名單 |
| **新 bug 調查** | 可離線調查根因、寫計畫書、spawn 修復 | 需照完整循環 |

### 5.3 離線禁止清單（紅線，自主運作仍不可越）
1. **改憲法**（須最高層同意）／改行政法僅限執行細則補正。
2. **push／改 git 歷史**／`git reset --hard`。
3. **排新 cron**、重啟 gateway（離線中無人在線收發）。
4. 碰 `~/teno/teno-backup.db`、`phone-db.db`（唯讀分析除外）。
5. 買資源／開付費 API／部署對外服務（免費 tokenrouter 可用，付費一律禁）。
6. 刪除使用者實體檔、格式化、任何具不可逆副作用之系統操作。

### 5.4 自主運作流程（離線波次）
1. 依行政法 §2 分組 spawn 首相（`hermes chat` 背景，不阻塞總統）。
2. 首相逐顆跑（計畫書→審查→動工→驗證→commit→md log）。
3. 總統離線監看 checks：commit 後 `git log`＋工作區核對（法典法律 §5）。
4. 每顆 commit 落 `_dev/notes/subagent-log/`（法律 §8）。
5. 預算/資源將盡 → 檢查點落盤 → 停（法律 §3 殘局）。

### 5.5 離線監督線程（全自動自持核心）
離線 8 小時，首相可能掛掉／預算爆／端點 4xx／無限迴圈。**總統離線期間開一個背景監督循環**（terminal background / cron 無人在線不外加，用現有 hermes 背景 process），定時（每 15-20 分鐘）：
1. `git log --oneline -5` — 判上次 commit 時間戳。
2. `process poll` 首相 session — 判存活。
3. `grep -E "❌|error|EXIT=1|429" pm*.spot.log` — 判端點/查詢失敗。

**成果門檻（無進展判定）**：距上次 commit > 60 分鐘 → 介入。

### 5.6 自動接手規則（著失敗行動圖）
| 偵測徵狀 | 判讀 | 接手動作 |
|---|---|---|
| 首相 session 結束（exit）| 預算盡/被停 | 讀其檢查點 → 總統續跑下一顆或重 spawn 該首相 |
| 首相卡住（60min 無 commit＋session 還活著）| 迴圈/等待 | kill → 讀 spot.log 找停點 → 手動補那一顆 → 重 spawn 續跑 |
| 端點 429/401 連續 | 免費 API 限流 | 等退避（429 建議 sleep 60s 重試；401 換 key/降級純離線）|
| git conflict / index.lock | 多首相併寫 | sleep 3-5s 重試（GOV-BRIEF §8）|
| 審查連續 >2 輪同類缺陷被退 | 憲法⑩ | 重估替代結構，升版 |

### 5.7 自動檢查點（防斷線失憶）
離線波次每完成 N 顆（建議每 3 顆）或每 2 小時，總統主動落 `_dev/notes/離線波次-checkpoint.md`：
- 已 commit 清單（hash＋版本）、進行中首相＋其停點、下一顆、pending 優先生成。
- 萬一總統 session 中斷，下一 session 讀此 checkpoint 即接續，不重新調查。

### 5.8 全自動運作終態判定
- **實現**：dispatcher 式 `all_done`（每組佇列 grep `fix: <ID>` 全數在 git log）→ 離線波次宣告完成。
- **未達**：時間/資源耗盡 → 檢查點落盤 → 停（等最高層醒來續）。

### 5.9 結束與回報
- 最高層回線 → 總統**立即停止自主運作**，下條指令為準。
- 回報格式：已完成 commit 清單（hash＋版本）、審查輪數、待辦殘局、計劃書路徑、未完成事項。
- 最高層醒來問「剩什麼」→ 以最新 `git log`＋session_search 實答，不憑記憶。

### 5.10 與法典關係
- 本節為行政法下位之授權執行細則；不牴觸法典憲法/法律各條。
- 授權範圍若與法典牴觸 → 以法典為準（本節不擴權）。
