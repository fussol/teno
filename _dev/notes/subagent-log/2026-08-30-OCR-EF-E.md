## 動工範圍（達成）
- `src/lib/ocr/vision-adapter.js`（新增）：`default{id:'vision-ai',available,recognize}`。
  - `available()`: desktop-only（`isDesktopEnv()` = UA 排除 Android/Mobi + `window.__TAURI__?.core`），手機短路不發請求；桌面才 ping `/api/tags` 驗 vision model 存在（`split(':')[0]` 主名比對，兼容 `qwen3-ocr64k:latest` 尾綴）。
  - `recognize(file,opts)`: `fileToDataUrl(file)` → fetch `${url}/api/chat` `{model,messages:[{role:'user',content,images:[dataUrl]}],stream:false}` → `parseChatToOcrResult`（先 message.content，備援 response/text）。
  - 測試 seam: `_setVisionConfig`/`_setVisionFetch`（僅 harness 注入，正式不呼叫）。
  - 組態: `getSetting('ollamaUrl')` fallback `http://localhost:11434`、`getSetting('ocrVisionModel')` fallback `qwen3-ocr64k`。
- `src/lib/ocr/engine.js`（改）：`registerEngine('vision-ai', async () => (await import('./vision-adapter.js')).default)`。
- `src/pages/ocr.js`（改，僅 E′ hunk）：`_ENG_LABELS['vision-ai']`、`_isDesktop()`、`engineSelectOptions(isDesktop)` 純函式 filter vision-ai 僅桌面列出、render `<select>` 改用 engineSelectOptions。
- `tools/verify-ocr2-vision.mjs`（新增 harness）。
