### 3. ①b WRITE maxSdk=28 保留論證——⚠️ 決定可守，證據鏈有誤（勘誤 E1）
- 宣稱：TtsPlugin.saveExportFile（:248-272）的 MediaStore.Downloads insert 在 API 24-28 需 WRITE 權。
- 實查：SDK api-versions.xml 實證 `MediaStore$Downloads since="29"`。minSdk=24 → **API 24-28 裝置上 `MediaStore.Downloads.EXTERNAL_CONTENT_URI`（非編譯期內聯的 Uri 欄位）觸發類解析 → NoClassDefFoundError**（Error，不被 `catch (e: Exception)` 捕獲，經反射 InvocationTargetException 化後至多 reject）。即：該代碼路徑在 24-28 本就跑不通，與給不給 WRITE 無關——「maxSdk=28 恰為精確收斂形態」的成對論證在本代碼庫不成立。
- 「pre-Q MediaStore 外部寫入需 WRITE」為一般性正確教科書事實，但套於此消費者屬错配。
- 影響評估：**低**。保留 maxSdk=28 是零風險保守決定（normal 權限、maxSdk 收斂、無上架違規面），T2 釘防一刀切方向正確；F6 動作（僅刪 MANAGE）不受影響。勘誤處方見裁決段。建議另單：TtsPlugin saveExportFile 在 API 24-28（minSdk 宣稱域）匯出必壞——真缺陷、F6 範圍外。
