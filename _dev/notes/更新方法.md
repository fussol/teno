# Teno 更新方法

## 前置需求

```sh
# 安裝 build 依賴（只需做一次）
sudo pacman -S --needed rust cargo nodejs npm
pip install --break-system-packages piper-tts
```

## 更新步驟

```sh
# 1. 進入新版專案目錄
cd /home/jupiter/下載/teno方案/2026.07.07/teno01.02.22

# 2. 如有新版原始碼，更新 PKGBUILD 裡的版本號
#    pkgver=新版號

# 3. 清除舊的無效套件檔（避免 makepkg 誤判已建置）
rm -f ./*.pkg.tar.zst

# 4. 建置 + 安裝
makepkg -si
```

若 binary 尚未編譯，先執行：

```sh
npm run tauri build
```

再執行 `makepkg -si`。

## 卸載

```sh
sudo pacman -R teno
```
