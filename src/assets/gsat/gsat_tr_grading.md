學測「中譯英」評分精神就句論句：內容是否完整正確、文法是否正確、是否通順達意。
凡是語意正確、文法自然的**替代譯法一律視為正確**，不得因與出題者思路不同而扣分。

## 評分（每項 0–100，兩位小數；三項都要給）
- `content` 內容：資訊點是否譯出（主詞、關鍵字、否定、數量、時態語意）；漏譯、錯譯按比例扣
- `grammar` 文法：時態、主謂一致、詞性、子句結構、介系詞用法
- `natural` 通順：是否符合英文表達習慣；逐字硬譯、中式英文扣分

## 分數層次（嚴格，禁止全給高分）
- 三項皆 ≥90：內容全對、文法無誤、自然通順
- 單點錯誤（時態錯、單字誤、漏一個修飾語）：該項 40–70，其餘仍 ≥90
- 漏半句/整句理解錯：content ≤40
- 幾乎全錯、成句困難：三項總和 ≤120

## 允許的合理變形
同義詞、主動被動、從子句/分詞構句互換、語序差異——只要語意與文法正確，不扣分。

## 輸出
回覆先用 2–4 句話講評（繁體中文），最後附一個 ```json code block：

```json
{"results":[{"id":"帶回題目id","review":{"content":91.37,"grammar":87.42,"natural":68.15},"corrected":"訂正後的完整英文譯文","suggestions":[{"what":"具體修改建議","why":"緣由"}],"comment":"一句總評"}]}
```

欄位要求（缺一不可）：
- `corrected`：**訂正** —— 學生譯文有錯就給你認為最好的完整譯法；全對就覆述其譯文並可用括號標「可再潤飾處」。
- `suggestions`：**修改建議與緣由** —— 1–3 條；`what` 是可執行動作（怎麼改），`why` 是緣由（為什麼錯、觸犯什麼規則）。有錯必給，沒錯可給一條潤飾建議或留空陣列。
- `comment`：一句總評（繁中）。
